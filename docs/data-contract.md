# 温度场与双留出

每行day唯一，values齐全列出全部cell，null是未观测。area是相同单位的正权重，不按有效观测次数重定义。early为训练，validation为选秩尾段，两者合起来是开发窗，external为独立外期，窗口含首末日且互不重叠。context_cells与target_cells固定且不相交，均只能引用现有格。

训练目标只包括观察位，不先填零。全开发重拟合时仍不使用external；外期投影只读该行非缺测context。符号规则为每模态面积加权绝对载荷最大的格取正，同值取最小cell_id；近重根的子空间用投影矩阵或重建比较，不执意逐向量一致。能量排序可通过模态空间内的正交旋转完成，不改变拟合。相对目标变化与参数可识别性是不同诊断。

`lowrank.analyze`在上述口径下产出：各窗日期与行、列筛选（kept/dropped/mapping，含全空列与有效数不足原因）、训练/验证/开发/外期观察掩码存档、逐秩的观察目标/停止原因/目标是否下降/多起点数与可识别性标识、尾段验证的逐行context/target评分与选秩（同分取较小r，无可评分行不选秩）、开发窗重拟合模态（能量、符号、面积正交载荷、等价子空间、投影矩阵、分数、均值）以及同规则外期结果。多起点择优只声称局部拟合，`global_optimum_claimed`恒为false。

不可识别情形显式标记而非数值掩盖：整行缺测不估时间分数；观察二部图不连通、行已观察载荷列不足秩、列观察行不足秩或秩超过维数时不做该秩拟合，禁止用随意ridge生成看似确定的值。局部最小二乘秩不足时自由分量置零并报告数值秩。验证/外期行target为空或context秩不足时单列、不参与评分。

domain只清点观察掩码，不估均值、分数、模态或填补。
