# 温度场与双留出

每行day唯一，values齐全列出全部cell，null是未观测。area是相同单位的正权重，不按有效观测次数重定义。early为训练，validation为选秩尾段，两者合起来是开发窗，external为独立外期，窗口含首末日且互不重叠。context_cells与target_cells固定且不相交，均只能引用现有格。

训练目标只包括观察位，不先填零。全开发重拟合时仍不使用external；外期投影只读该行非缺测context。符号规则为每模态面积加权绝对载荷最大的格取正，同值取最小cell_id；近重根的子空间用投影矩阵或重建比较，不执意逐向量一致。能量排序可通过模态空间内的正交旋转完成，不改变拟合。相对目标变化与参数可识别性是不同诊断。

domain只清点观察掩码，不估均值、分数、模态或填补。
